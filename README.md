# IMAGRO Construction Website

A premium, modern corporate website for IMAGRO Construction - an international construction and engineering company.

## Features

- 🏗️ Full-stack Next.js application with TypeScript
- 📱 Fully responsive design (mobile, tablet, desktop)
- ✨ Smooth animations and transitions
- 🎨 Professional industrial/corporate design system
- 🌍 International presence across Egypt, Middle East, Africa, and Europe
- 📧 Contact form with email integration
- 🚀 SEO optimized with meta tags
- ⚡ Production-ready code

## Pages

- **Home** - Hero section with company overview
- **About** - Company mission and vision
- **Services** - Comprehensive service offerings
- **Projects** - Portfolio of selected projects
- **Experience** - Expertise and statistics
- **Contact** - Contact form and information

## Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: React
- **Icons**: React Icons
- **Animations**: Intersection Observer API

## Getting Started

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

```bash
npm install
# or
yarn install
```

### Development

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### Production Build

```bash
npm run build
npm run start
```
